# Wealth Tax Simulator

A small GitHub Pages site that lets you simulate annual wealth taxes for two region-specific example models: Zurich (Canton + City) and Mallorca (Balearic Islands, Spain — 2024 autonomous scale).

The models are implemented from official sources and are included in `script.js` as configured model objects. The Balearic model implements the 2024 mínimo exento (3,000,000 EUR) and the autonomous bracket scale. The Zurich model implements the canton progressive promille tariff and applies the Staatssteuerfuss and Stadt Zürich Gemeindesteuerfuss to compute total tax.

Important: These calculators are illustrative. Verify official sources or use the official tax calculators before making legal or financial decisions.

Deployment: enable GitHub Pages in repository settings on the `main` branch (root).
